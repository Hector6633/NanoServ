NanoServ
Step 1: To Clone the project
Step 2: Create a new virtual environment with this command "python -m venv your virtual environment name"
Step 3: To activate virtual environment using this command "virtualenvironmentname/Scripts/activate"
Step 4: To install django and project dependencies and package using this command "pip install -r requirements.txt"
Step 5: Then, run the project using this command "python manage.py runserver"
